# Task Reminder

A planned small Graveyard Keeper mod that keeps weekday-related tasks visible below the calendar on the left of the screen.

The initial idea is to show reminders for the current day, with an optional next-day preview under consideration. Task selection and visual design are still being discussed.

**Status:** planning and research preparation. There is no installable mod or release yet.

The initial research target is Graveyard Keeper 1.407 on Windows with BepInEx 5. Compatibility has not yet been tested for this project.
